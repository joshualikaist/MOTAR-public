## 사전등록 예측과 판정 규칙

시드마다: T0의 stopcap−riskcap ≤ −3 pp(CI 0 제외), T1은 ±2 pp 안(CI 0 포함). 판정은 상호작용
(T1 차이 − T0 차이)으로 한다 — 양수·유의면 "riskcap과 함께 학습하면 정지법칙 손해가 사라진다"는
동반학습 설명이 재현된 것. **2/2 재현 → 동반학습으로 쓴다. 1/2 → 이 계보에서 관측으로 좁힌다.
0/2 → C3 철회.**

## 시드별 추정량 (Wald 95% CI)

| | T0: stopcap−riskcap | T1: stopcap−riskcap | 상호작용(T1−T0) |
|---|---:|---:|---:|
| seed 233 | −2.93 [−5.12, −0.75] | **−8.59 [−11.14, −6.04]** | **−5.65 [−9.01, −2.30]** |
| seed 239 | −8.69 [−11.15, −6.22] | **−7.17 [−9.68, −4.67]** | +1.51 [−2.00, +5.03] |

**둘 다 CI가 0을 제외해야 할 T1 예측(±2pp, CI 0 포함)을 정면으로 벗어난다.** T1(riskcap과 함께 학습한
정책)도 T0 못지않게 큰 stopcap 손해(−7~−9 pp)를 보인다. 상호작용은 seed 233에서 **반대 방향으로
유의**하고(T1이 T0보다 더 나쁘다), seed 239에서는 방향은 원 가설과 같지만(+1.51) 불유의하다.

풀링(고정효과, 역분산): T0 stopcap−riskcap **−5.46 [−7.10, −3.83]**, T1 **−7.87 [−9.66, −6.08]**.
둘 다 유의하게 음수이고 구간이 크게 겹친다 — 학습 필터가 두 정책을 갈라놓지 못했다.

## 판정: **0/2 — C3 철회**

두 학습 시드 모두 원 가설("riskcap과 함께 학습하면 정지법칙 손해가 검출되지 않는다")을 재현하지
못했다. seed 197(09-05 D4)에서 관측된 T1 무손해는 **그 특정 실행 하나의 속성이었을 가능성이 높고,
시드를 반복하면 사라진다.** 대체 결론: 이 계보(`ref5in` a8-readapt)에서 stopcap의 capture 손해는
학습 시 어떤 속도 거버너와 함께였는지와 무관하게 나타난다 — 학습 필터 선택이 이 손해를 막아주지 않는다.

## 주장하지 않는 것

- "riskcap 학습이 stopcap 손해를 악화시킨다"도 아니다. seed 233만 그 방향이고 seed 239는 반대(불유의)라
  방향 자체가 시드 간 불일치다. 유일하게 두 시드 모두 유의한 것은 "T1도 T0만큼 나쁘다"는 것뿐이다.
- 70 bars, `ref5in` 계보, 평가 시드 521 하나에 한정된다. 다른 밀도·계보로 일반화하지 않는다.

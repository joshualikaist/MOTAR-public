## 고친 것 — 행동이 아니라 가드

동결해야 하는 것은 저장소 전체가 아니라 **평가되는 소스**다. HEAD 비교를 `aerial_gym`·`tools`·
`resources/robots` **세 경로의 git tree 해시**(`git rev-parse HEAD:<path>`) 비교로 바꿨다.

- 그 경로들의 커밋된 내용이 바뀌면 여전히 VOID (체크아웃·리베이스도 잡힌다).
- `docs/`·`results/` 커밋은 이제 통과한다. 실행 중에도 문서를 쓸 수 있다.
- 미커밋 변경 검사는 그대로 세 경로에 대해 유지.
- `cells.json`에 `evaluated_source_fingerprint`와 `frozen_paths`를 함께 기록한다.

테스트 4개(`tests/test_navrl_filter_grid.py::SourceFreeze`)가 임시 저장소에서 네 경우를 고정한다:
문서 커밋은 지문 불변, 런타임 커밋은 지문 변화 + VOID, 런타임 미커밋은 거부, 문서 미커밋은 허용.

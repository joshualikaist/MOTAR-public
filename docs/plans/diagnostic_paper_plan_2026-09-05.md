## 0. 주장 한 문장

> 명령 방향을 보존하고 크기만 조정하는 속도 안전필터에서, **충돌의 77~78 %는 그 필터가 감시하는
> 영역 밖에서 발생한다.** 더 엄격한 정지거리 법칙은 자기 안전모델을 만족시키면서도 충돌을
> **늘렸고**, 정교한 해제 기구는 상수 상한을 이기지 못했다.

이것은 **부정 결과를 요점으로 삼는 논문**이다. 조사에서 확인한 두 가지가 이를 지지한다:
안전필터가 단순 baseline을 못 이긴 정직한 ablation이 문헌에 **없고**, 노출시간 기제를
**충돌률**에 귀속시킨 문헌도 **없다**.

## 3. 단계

### A1 — 재현 (D1 해소) · GPU ~1시간

seed 491을 **497**로 바꿔 접촉 포렌식 2 arm을 그대로 재실행한다. 코드 변경 없음.

- **판정**: `LATERAL`과 `lateral + no_return` 합계가 seed 491의 95 % CI 안에 들어오는가
- 벗어나면 **표를 내지 않는다.** 시드 민감성이 있다는 뜻이므로 시드를 늘린다

### A2 — 누락 지표 (D4·D5 해소) · 계측 추가 + A1과 동시 실행

접촉 포렌식 계측에 넷을 더한다. 전부 평가 전용, 기존 경로 무변경.

1. **궤적 전체 회랑 clearance 히스토그램** — "안전해져서 느려진 것"을 잡는 지표
2. **경로 길이** — 우회 비용
3. **거버너 계산시간** (평균·최대) — 문헌 관행(HOCBF 90.6 µs / 최대 384.5 µs)과 비교 가능하게
4. **비접촉 프레임의 `cmd_vs_actual_deg`** — 예측 6을 평가 가능하게

### A3 — 처방의 반사실 (D2 해소) ★ **핵심 단계** · 구현 3~5일 + GPU 1시간

**Star-Convex Polytope를 shadow mode로 돌린다.** 정책 경로는 손대지 않고, 같은 프레임에서
"SCP였다면 이 접촉이 회랑 안이었나"만 기록한다. S1 shadow와 동일한 구조이고 M1(관측 비트 동일)도
같은 방식으로 건다.

- 288 반환 + 구 경계 샘플 → 뒤집기 → 볼록껍질 → `point-in-SCP`
- **측정**: E2의 `LATERAL`·`NO_RETURN` 접촉 중 몇 %가 SCP 안에서는 **사전에 감지되었나**
- **판정 (결과 이전 동결)**: 재분류율 ≥ 50 % → `PRESCRIPTION_SUPPORTED` · < 20 % → `INSUFFICIENT` ·
  그 사이 → `PARTIAL`

**이 단계가 논문을 "문제를 보였다"에서 "무엇을 고쳐야 하는지도 보였다"로 올린다.**
그리고 활성 A/B(비싸고 실패 위험 큼) 없이 그것을 한다.

### A4 — 외부 baseline (D3 해소) · 구현 2~3일 + GPU ~2시간

거버너에 **arm 두 개**를 추가한다. 둘 다 기존 모드와 같은 인터페이스다.

- **`dwa_arc`** — 직선 회랑 대신 현재 `(v, ω)`가 만드는 **원호**를 따라 `dist(v,ω)` 계산
  (Fox et al. 1997 Eq. 14). 우리 회랑과 **같은 정보로** 기하만 바꾼 대조군
- **`omni`** — 방위 무관 전방향 최근접까지의 정지거리 상한. **"그냥 다 보면 되는 것 아닌가"**에
  대한 가장 단순한 답이자, SCP가 이겨야 할 최소 baseline

E7의 교훈이 여기 적용된다 — **정교한 것이 단순한 것을 못 이길 수 있으므로, 단순한 것을 먼저 넣는다.**

### A6 — 집필 · 2주

**구조**: ① 방향 보존 속도 거버너의 계보(trajectory scaling / SSM / nav2_collision_monitor)와
우리 위치 → ② E1 역설 → ③ E2 분해 → ④ 대안 설명 배제(E4·E5·E6) → ⑤ E7 null →
⑥ A3 처방 반사실 → ⑦ 한계.

**명명 동결**: *direction-preserving speed governor with a liveness floor*.
**CBF·shield·"provably safe"로 부르지 않는다** — forward invariance도 recursive feasibility도 없다.

**반드시 답할 반론**: DWA 원논문 §2의 *"무한한 힘을 낼 수 있을 때만 정당하다"*. 우리 답은
"방향을 정하는 것은 clutter를 이미 관측한 학습 정책이지 기하학적 heading planner가 아니다"이며
A4의 `dwa_arc` arm이 그 답을 정량화한다.

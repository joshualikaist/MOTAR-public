## 4. 판정·보고 규칙 (동결)

1. 모든 표는 **개수/n**을 싣고 비율은 그로부터 계산한다. 95 % Wald CI. 임계 3 pp(단, C4는 결합 CI의 0 제외로 판정).
2. 결합은 역분산 가중, cell은 서로 다른 에피소드라 표본 오차 독립. 이질성 Q와 I²를 함께 적는다.

## 1. 가르려는 것

v7 검출기로 교체했을 때의 nominal 항법 손실(**−5.19 pp**, 95% CI [−6.98, −3.40],
seeds 191/193, `results/navrl_v2_detector_threshold_diagnostic_seed191_193/`)의 원인:

- **(a) 결합 가설** — 정책이 analytic 검출기의 *출력 통계*에 맞춰 학습돼 있어서, 통계가 달라지면
  그 자체로 손해를 본다. → 해법은 matched fresh training (D3 / 5C).
- **(b) 출력 성질 가설** — v7의 출력이 항법에 쓰기에 그냥 덜 유용하다(어떤 정책이 봐도). →
  해법은 관측 표현 변경.

재학습 없이 가른다: v7의 오차 통계를 프로파일링해 **analytic 출력에 합성 잡음으로 주입**하고,
동결 정책에서 v7 실물과 비교한다.

## 2. 이 방법의 알려진 한계 — 판정 전에 명시

**(L1) 재현 실패는 (b)를 지지하지 않는다.** 세 번째 설명이 항상 남는다: *잡음 모델이 부실함*.
v7의 오차는 상관구조를 가질 가능성이 높다 — 마스크 내 공간 상관, 프레임 간 시간 상관(한 번
놓치면 연속으로 놓침), 장면 조건부(특정 색상·거리·가림에서 실패). **주변분포만 맞춘 iid 주입은
효과를 계통적으로 과소재현한다.** 이는 검증 3에서 지적된 것과 같은 실패 양식이다(스텝별 iid
가우시안 ≠ 바이어스·드리프트를 가진 실제 odometry).

→ **대응**: 주변분포에 더해 **미검출 연속길이 분포**와 **거리·마스크크기 조건부 오차**까지
프로파일링하고, 드롭아웃을 iid Bernoulli가 아니라 **연속길이를 맞춘 2-상태 Markov**로 주입한다.
그리고 §6의 판정 규칙에 "잡음 arm이 이 구조들을 재현했는지"를 **선행 조건**으로 박는다.

**(L2) 재현 성공도 (a)를 확정하지 않는다.** 재현이 보여주는 것은 "이 오차 통계가 *이* 정책을
해친다"이지 "*이* 정책이 analytic 통계에 특별히 결합돼 있다"가 아니다. 후자는 같은 통계로
학습한 정책이 손해를 보지 않음을 보여야 하고, 그것은 정의상 재학습(D3/5C)을 요구한다.
따라서 본 실험의 최대 결론은 **"결합 가설과 정합적이며 D3를 정당화한다"**까지다.

**(L3) 공변량 이동.** 프로파일링은 analytic이 조종하는 궤적 위에서 v7의 오차를 잰다. 실제 v7
arm은 v7이 조종하므로 다른 상태 분포를 방문하고, 거기서의 오차 분포는 다를 수 있다.

**(L4)** 단일 정책·단일 아레나·단일 밀도. 일반화 주장 없음.

## 4-b. 프로파일 결과에 따른 잡음 모델 확정 (2026-08-13, **arm 실행 전** 기록)

프로파일링(seed 419, riskcap, capture 79.16%)이 §2 (L1)의 우려를 **부분 확증, 부분 해소**했다.

| 축 | 측정값 | 함의 |
|---|---|---|
| 미검출 (v7 놓침 \| analytic 봤음) | **2.1e-5** | 사실상 없음 → Markov 구조 우려 **해소** |
| bearing 오차 std | 0.000827 rad (**0.047°**) | 무시 가능 |
| **range 오차 std** | **0.705 m** | **지배적 채널** |
| range 오차 lag-1 자기상관 | **0.644** | **백색 아님** → iid 주입은 과소재현 |
| range 오차 std, 거리 4분위 | 0.42 / 0.37 / 0.23 / **1.07 m** | **이분산** → 단일 σ는 과소재현 |
| range 오차 평균 | +0.045 m | 소폭 편향 |
| 픽셀 수 비 (중앙값) | 1.045 | v7 마스크가 4.5% 큼 |

따라서 §2가 예고한 대로 **주변분포가 아니라 구조를 맞춘다**. 주입 모델을 확정한다:

```
e_t = ρ·e_{t-1} + √(1−ρ²)·w_t ,  w_t ~ N(0, σ(range)²)
ρ = 0.6442,  σ_pooled = 0.7053 m,  bias = +0.0453 m
σ(range) 배수 = 2.08 m 이하 0.591 / 4.66 이하 0.518 / 8.64 이하 0.331 / 그 이상 1.516
```

√(1−ρ²)가 정상분산을 σ²로 유지하므로 ρ는 상관만 바꾸고 프로파일이 고정한 주변분포는 건드리지
않는다. 해석적 검증: 주입 std 0.7051(목표 0.7053), lag-1 0.6439(목표 0.6440).

**이는 결과를 본 뒤의 조정이 아니다** — arm은 아직 하나도 돌지 않았고, §2가 처음부터 요구한
"구조까지 맞춘다"의 이행이다. §8이 금지하는 것은 *결과를 본 뒤* 잡음을 손보고 재실행하는 것이다.

**주입하지 않는 축(명시)**: 마스크 크기. 프로파일에는 남기되 주입하지 않는다 — 마스크 형상을
바꾸려면 침식/팽창이 필요해 구현 복잡도가 크고, 게이트 0은 애초에 이 축을 요구하지 않는다.
따라서 재현 실패 시 "마스크 채널 미주입" 이 대안 설명으로 남는다.

**게이트 0 갱신**: 드롭아웃이 사실상 0이므로 연속길이 KS 조건은 공허하게 충족된다. 실질 조건은
**주입 range 오차의 실측 std가 0.705 m의 ±10% 이내이고 lag-1 상관이 0.644의 ±0.10 이내**인 것.

## 5. 평가 arm (seed 409)

용량-반응 사다리를 포함한다. 단일 점 일치보다 **곡선이 1.0×에서 −5.19 pp를 지나는지**가 훨씬
강한 증거이고, 셀 2개(약 10분) 추가 비용밖에 들지 않는다.

| # | arm | 검출기 | 잡음 |
|---|---|---|---|
| 1 | `analytic_clean` | analytic | 없음 (기준) |
| 2 | `analytic_noise_0p5` | analytic | v7-matched × 0.5 |
| 3 | `analytic_noise_1p0` | analytic | **v7-matched × 1.0** |
| 4 | `analytic_noise_1p5` | analytic | v7-matched × 1.5 |
| 5 | `learned_v7` | v7 @0.55 | 없음 (실물) |

잡음 스케일은 bearing/range 오차의 표준편차와 드롭아웃 확률에 곱해진다(연속길이 구조는 유지).

**RNG 격리 필수** — 잡음 생성은 검증 3의 `pose_noise_seed` 패턴을 그대로 따라 전용 시드
생성기를 쓴다. 전역 torch RNG를 소비하면 arm마다 장애물 배치·표적 이동이 달라져 비교가 무효가
된다(이 실수는 이미 한 번 캠페인을 폐기시켰다).

## 6. 판정 규칙 — 결과를 보기 전에 확정

`Δ₃ = arm3(1.0×) − arm1(clean)`, `Δ₅ = arm5(v7) − arm1(clean)`, 목표값 `−5.19 pp`.

**선행 조건 (게이트 0)** — 아래를 만족하지 못하면 어떤 판정도 하지 않고 "잡음 모델 불충분"으로
보고한다:
- 주입된 드롭아웃의 실측 연속길이 분포가 프로파일과 KS 거리 ≤ 0.10
- 주입된 bearing/range 오차의 실측 표준편차가 프로파일의 ±10% 이내

**판정**

| 조건 | 결론 |
|---|---|
| `Δ₃`의 95% CI가 `Δ₅`의 점추정을 포함하고, 사다리가 단조(‖Δ₀.₅‖ < ‖Δ₁.₀‖ < ‖Δ₁.₅‖) | **결합 가설 지지** → 다음 수는 matched fresh training (D3/5C). 단 §2 (L2)의 한계를 함께 기술. |
| `Δ₃`가 `Δ₅`의 **절반 미만**(즉 \|Δ₃\| < 2.60 pp)이고 게이트 0 통과 | **결합만으로 설명 안 됨** → v7 출력 성질 쪽 무게. 다음 수는 관측 표현 변경. |
| 그 사이 | **미결(INCONCLUSIVE)**. 사후에 기준을 옮기지 않는다. |
| 사다리가 비단조 | 잡음 파라미터화 결함 의심 → 판정 보류 |

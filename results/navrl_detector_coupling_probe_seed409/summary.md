## 4. 판정 — 게이트 0 실패

사전등록 §6의 게이트 0은 "주입 range 오차의 실측 std가 0.705 m의 **±10% 이내**"를 요구한다.

**실측: 0.6134 m (−13.0%). 실패.**

원인을 분해했다. 프로파일의 pooled 분산은 두 성분이다:

```
pooled var 0.4974  =  구간내 분산 평균 0.3765  +  구간간 *평균* 분산 0.1210
```

내 주입은 **구간내 분산만** 재현하고, 구간별 평균(+0.205 / +0.305 / +0.224 / −0.554 m)을 단일
전역 bias(+0.045 m)로 뭉갰다. 즉 v7 오차의 **거리 의존 계통 편향**을 통째로 빠뜨렸다.

사전등록은 "게이트 0을 만족하지 못하면 **어떤 판정도 하지 않는다**"고 못박았다. 따라서 형식적
판정은 **INCONCLUSIVE(잡음 모델 불충분)**이며, 결과를 보고 게이트를 완화하지 않는다.

### 다만 실패 방향이 보수적이다 — 이것도 결과다

주입한 잡음은 v7 실제 오차보다 **약하다**(−13% std, 계통 편향 누락). 그런데도:

- Δ₃ = **−3.45 pp**로 Δ₅ = −4.20 pp의 **82%**를 재현했다
- Δ₃의 95% CI [−5.91, −1.00]이 Δ₅의 점추정 −4.20을 **포함**한다
- 사다리가 단조다

즉 사전등록의 1차 판정 조건(§6 첫 행)은 **충족**되었고, 게이트만 보수적 방향으로 빗나갔다.
사다리를 선형 보간하면 v7의 −4.20 pp는 **scale ≈ 1.10**에서 재현되는데, 13% 과소주입을 보정하면
실효 배율은 ≈0.96 — 사실상 1.0×다. (이 산술은 **사후 계산**이며 사전등록 판정의 일부가 아니다.)

**따라서 방어 가능한 진술**: *analytic 검출기 출력에 v7의 측정된 오차 통계를 주입하는 것만으로
v7 교체 손실의 대부분이 재현된다. 이는 결합 가설과 정합적이며 D3(matched fresh training)를
정당화한다.* 확정을 위해서는 §6의 수정판을 새 시드로 재사전등록해야 한다(§6 참조).

## 5. 이 결과가 보장하지 않는 것

- **(a) 결합의 확정이 아니다.** 보여준 것은 "이 오차 통계가 *이* 정책을 해친다"이지
  "*이* 정책이 analytic 통계에 특별히 결합돼 있다"가 아니다. 후자는 같은 통계로 학습한 정책이
  손해를 보지 않음을 요구하며, 그것은 정의상 재학습(D3/5C)이다. (사전등록 §2 L2)
- **마스크 채널 미주입.** 마스크 크기·형상은 프로파일만 했고 주입하지 않았다. 잔여
  −0.75 pp(Δ₅−Δ₃)의 일부가 여기에 있을 수 있다.
- **공변량 이동.** 프로파일은 analytic이 조종하는 궤적에서 쟀다. 실제 v7 arm은 v7이 조종하므로
  다른 상태를 방문하고 거기서의 오차 분포는 다를 수 있다. (§2 L3)
- 단일 정책, 단일 아레나, 단일 밀도, 평가 시드 1개. 일반화 주장 없음.

## 6. 다음 단계 (재사전등록 필요)

1. 주입에 **구간별 bias**를 추가한다(단일 전역 bias → 거리 의존 bias). 이것만으로 게이트 0의
   13% 격차와 누락된 계통항이 동시에 닫힌다.
2. 새 평가 시드로 3-arm(clean / 보정된 1.0× / v7)을 재사전등록해 돌린다. GPU 약 15분.
3. 그 결과가 게이트 0을 통과하고 1차 조건을 유지하면 결합 가설 지지를 확정하고 D3로 간다.

**하지 않은 것**: 5C 재학습 미착수(요청대로), 임계값 재튜닝 없음, 판정 기준 사후 변경 없음.
